A public Claude Code skill, Site Analysis Analyst, that points an agent at a codebase and gets back a structured read on what it does, who it's for, and what it's built on, instead of a raw file listing.

View the skill

The idea

A checklist an agent actually follows

Pointing an agent at an unfamiliar repo and asking "what is this" usually gets a summary of file names, not an analysis. A skill is a packaged set of instructions Claude Code loads for a specific kind of task, and this one packages the questions a senior engineer would actually ask first: what problem does this solve, who is it built for, what does the public surface expose, and what is the stack actually running on.

It works by reading the artifacts a codebase already carries, package.json, entry-point HTML, deployment config like railway.json or a Procfile, rather than asking the model to guess, and it explicitly bans marketing language in the output so the result reads like engineering notes, not a pitch deck.
